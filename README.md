- Projeto ETL Simples com Python

Este projeto foi desenvolvido como parte de um estudo introdutório de Engenharia de Dados, com foco no entendimento do processo de ETL (Extract, Transform, Load) utilizando Python.

- Objetivo

Simular um fluxo básico de processamento de dados utilizando um arquivo CSV como fonte, realizando transformações simples e gerando um novo arquivo de saída.

- O que é ETL?

- Extract (Extração): leitura dos dados de um arquivo CSV  
- Transform (Transformação): processamento e criação de mensagens personalizadas  
- Load (Carregamento): geração de um novo arquivo CSV com os dados tratados  

- Tecnologias utilizadas

- Python 3  
- Biblioteca CSV (nativa do Python)  

- Como executar

1. Tenha o Python instalado  
2. Coloque os arquivos na mesma pasta  
3. Execute o script:

python etl.py

- Aprendizados

- Leitura de arquivos CSV  
- Manipulação de dados com Python  
- Estrutura básica de ETL  
- Organização de código
